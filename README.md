# NOVA

**毎日の行動が、自分だけの街になる。**

NOVA v0.1 は、日々のタスクを完了するとコインと街EXPが増え、ガチャで住民・建物・デコを集められるスマホ向けPWAです。

## v0.1 機能
- 今日のタスク追加 / 完了
- タスク達成で +50コイン / +1 EXP
- マイシティのレベルアップ
- 1回 / 10連ガチャ
- 住民・建物・デコのコレクション
- localStorage保存
- PWA対応

## GitHub Pages
このリポジトリをPublicにし、Settings → Pages → Deploy from a branch → main / root を選ぶと公開できます。
